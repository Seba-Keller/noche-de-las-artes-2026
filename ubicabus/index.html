♥ Financiamiento colectivo

Participación voluntaria

Ayudanos a hacer realidad UbicaBus

El proyecto propone reunir aportes voluntarios para contribuir a la adquisición de módulos GPS, conectividad y servicios de alojamiento de datos.

Esta función es demostrativa. No se realizan cobros ni transferencias de dinero.
🎯 ¿Para qué serviría?

Para que los usuarios puedan conocer dónde se encuentra el colectivo y organizar mejor sus viajes.

Tecnologías previstas para el proyecto
🗺️

OpenStreetMap + Leaflet

Mapa interactivo para representar el recorrido y las paradas.

📡

GPS + ESP32 + 4G

Dispositivos que podrían obtener y transmitir la ubicación de las unidades.

☁️

Base de datos

Servicio que recibiría y almacenaría las coordenadas enviadas por los dispositivos.

⚠️ IMPORTANTE: PROTOTIPO DE DEMOSTRACIÓN
UbicaBus Merlo-Papagayos es un proyecto escolar en etapa de prototipado. La ubicación del colectivo, los tiempos de llegada y la trayectoria representada son simulados. Los puntos geográficos son aproximados y no constituyen coordenadas verificadas de paradas ni un trazado oficial del transporte. La plataforma no está conectada a empresas de transporte ni a dispositivos GPS reales. El módulo de colaboración tampoco procesa pagos.

♥ Colaborá con UbicaBus

El proyecto propone un sistema de aportes voluntarios para ayudar a financiar los dispositivos GPS, la conectividad y el alojamiento de la plataforma.

En una futura versión se podría integrar Mercado Pago mediante su entorno de pruebas (Sandbox), para demostrar el proceso de donación sin utilizar dinero real.

Esta es una simulación escolar. No se inició ningún pago ni se compartieron datos personales.
